# Dataset

This project uses the **MELD (Multimodal EmotionLines Dataset)** for multimodal sentiment analysis.

The dataset contains three modalities:

- Text
- Audio
- Video

The experiments use the official:

- Training split
- Development split
- Test split

## Dataset Structure

After downloading and preparing the dataset, organize it as follows:

data/
├── train/
├── dev/
└── test/

The complete dataset is not included in this repository because of its large size.

Please download the dataset separately and place the required files inside this directory.
